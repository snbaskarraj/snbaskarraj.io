Everpure Agentic Analyst — a governed analytics agent, built end to end under the clock

A conversational agent that answers questions about business metrics and business events, built in a single 60-minute live coding exercise: chat UI, LLM backend, a tool layer that queries and analyses the data, and answers grounded in it that can be audited line by line. Schema-agnostic ingestion means the interviewers' CSVs drop into data/ and nothing else changes.

The model plans; the tools compute. No number in an answer comes from the language model — totals come from DuckDB, and slopes, z-scores and percentage changes from numpy. SQL is validated to a single read-only SELECT, row-capped and logged. A write is only ever a proposal: the ledger holds it as pending until a named human clicks Approve, and on the LangGraph backend the graph itself freezes mid-turn before the write node.

Validation splits the way the problem does. 309 deterministic checks cover schema inference, SQL guardrails (DROP, DELETE, UPDATE, stacked statements and PRAGMA all rejected), aggregation semantics — revenue sums, gross margin averages, because summing nine segment margins gives 640% — the anomaly maths, the write ledger and the budgets. The non-deterministic half is a golden-question rubric scoring tool choice, groundedness and refusal, run by CI and the live UI through the same scorers, so the two cannot disagree about what "grounded" means. Two golden questions exist purely to test refusal, including one answerable from world knowledge that the agent must decline anyway.

One finding worth the room: the first anomaly detector scored raw month-over-month change and flagged 17 of 36 months on a series containing a single real incident — enterprise revenue peaks every quarter-end, so "moved a lot since last month" just describes the business. Estimating a seasonal profile from the data and scoring the residual with a median/MAD robust z-score cut it to five flags, all inside the real incident window.

Built with AI-assisted engineering — the same practice I rolled out across my team at Nutanix, under written accountability standards with human review required on generated code. The repository is public; the commit history and contributor list show exactly how it was made.
